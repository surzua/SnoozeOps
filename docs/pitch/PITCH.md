**Objetivo:** 4:45. La aplicación ocupa aproximadamente 2:50; no se usan diapositivas como sustituto de la demo.

## Reglas de escena

- Presentar P3 antes de P1 para hacer visible el contraste de rutas.
- Llamar al P1 “prueba de seguridad sintética”; nunca atribuirlo a la noche habitual.
- No abrir el switch de red salvo Q&A o si sobra tiempo: representa sólo conectividad simulada y no cambia el motor.
- No improvisar incidentes libres. Usar los fixtures y controles ensayados.
- No prometer una alerta imposible de perder: gravedad, ambigüedad o falta de confirmación se escalan de forma conservadora.
