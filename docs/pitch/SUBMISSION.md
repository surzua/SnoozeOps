# Auditoría de entrega — ciclo adaptativo

**Versión:** demo local sintética, pendiente de validar despliegue.

## Antes de entregar

- [ ] `npm run lint`
- [ ] `npm run typecheck`
- [ ] `npm test`
- [ ] `npm run build`
- [ ] Ensayar el recorrido central tres veces desde **Reiniciar escenario sintético**.
- [ ] Ensayar la caída del proveedor y confirmar que no se inventa una recomendación.
- [ ] Verificar la URL desplegada y anotar cualquier diferencia respecto de local.

## Declaración honesta

La demo usa únicamente fixtures sintéticas. El proveedor real es opcional y sus salidas pueden variar; una prueba simulada no lo sustituye. No se ha validado una hora adicional de sueño ni se debe afirmar causalidad a partir de estos registros.
